XML iniciales y después de cada tarea

Un ejemplo completo por slot del modelo. El nombre de cada fichero identifica el tramo sin necesidad de abrirlo.

Empieza por A01, B01 y C01 para ver las entradas. El flujo central S01–S16 muestra un alta procedente de CRM1. D01–D06 y R01 ilustran otra ejecución procedente de CRM2 para poder enseñar la salida hacia CRM1.

Una tarea que copia, ordena o enruta puede dejar el XML sin cambios. Cada fichero sigue representando un tramo diferente.

  • 01 Entrada CRM1
  • 02 Entrada CRM2
  • 03 Entrada CRM3
  • 04 Consulta y reserva BD auxiliar
  • 05 Salida hacia CRM1
  • 06 Salida hacia CRM2
  • 07 Salida hacia CRM3
  • 08 Respuestas y confirmaciones
  • 09 Rutas alternativas y errores
